# latkuis_124240137

Aplikasi Flutter katalog menu Gacoan untuk Latihan Kuis Praktikum Pemrograman Mobile SI-G.

## Struktur halaman

- `lib/pages/login_page.dart` — Login dan validasi
- `lib/pages/home_page.dart` — Katalog menu
- `lib/pages/detail_menu_page.dart` — Detail menu
- `lib/pages/profile_page.dart` — Profil dan Logout
- `lib/data.dart` — Data user dan data menu
- `lib/main.dart` — Entry point aplikasi

- Password: `1221`

## Menjalankan

```bash
flutter clean
flutter pub get
flutter run -d chrome
```

Project menggunakan Dart SDK `^3.10.9`.
